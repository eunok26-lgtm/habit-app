# 우리 아이 습관 앱

초등 저학년 아이가 하루 할 일을 스스로 체크하고, 이번 주 일정을 확인하는 웹앱입니다.

## 화면

- **오늘** — 아침 / 학교 다녀와서 / 잘 준비로 나뉜 할 일. 체크하면 진행 바가 찹니다.
- **이번 주** — 한 주 계획 보기. ✏️ 를 누르면 추가·수정·삭제할 수 있습니다.
- **일정** — 구글 캘린더에서 가져온 하교 시각과 학원 일정.

시간이 정해진 할 일에는 타이머가 붙습니다. 시작을 누르면 큰 화면으로 카운트다운이 돌고, 끝나면 알람이 울립니다.

## 구글 캘린더 연결

이 저장소는 공개라서 접속 주소와 암호를 넣어두지 않았습니다. 기기마다 한 번씩 설정해 주세요.

1. `google-calendar-relay.gs` 를 script.google.com 새 프로젝트에 붙여넣기
2. 맨 위 `SECRET` 을 원하는 암호로 변경
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
4. 나온 주소를 앱의 ⚙️ → 구글 캘린더 연결에 입력

캘린더 이름은 `우리딸일정` 과 `하교시간` 을 씁니다. 일정 제목 앞에 `2:00 피아노` 처럼 시각을 적으면 그대로 읽어냅니다.

## 저장

기록은 브라우저 안(localStorage)에 기기별로 저장됩니다. 기기 간 공유는 아직 안 됩니다.
