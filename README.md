# 우리 아이 습관 앱

초등 저학년 아이가 하루 할 일을 스스로 체크하고, 이번 주 일정을 확인하는 웹앱입니다.

## 화면

- **할 일** — 아침 / 저녁으로 나뉜 할 일. 체크하면 진행 바가 찹니다.
  좌우 화살표(또는 좌우로 밀기)로 지난 날과 다음 날을 볼 수 있습니다.
  ✏️ 고치기를 누르면 할 일을 추가·수정·삭제할 수 있습니다.
  시간대(아침·저녁 등)는 제목을 눌러 이름과 그림을 바꾸거나 지울 수 있고,
  ＋ 시간대 추가로 "학교 다녀와서", "저녁 먹고", "자기 전" 처럼 얼마든지 늘릴 수 있습니다.
- **내 일정** — 위젯을 골라서 꾸미는 화면. 오른쪽 위 ✏️(비밀번호)로 편집 모드에 들어가면
  ⠿ 를 잡아 끌어서 자리를 옮기고, 크기 버튼으로 작게/크게/전체를 바꾸고, 추가·설정·삭제할 수 있습니다.

### 위젯 종류

| 위젯 | 하는 일 |
|---|---|
| 🕐 시계 | 아날로그 + 디지털. 시계 보기 연습에도 좋습니다 |
| 🔔 하교 시각 | 오늘 학교가 끝나는 시각 (구글 캘린더) |
| 📌 오늘 일정 | 하교 후 학원·약속 (구글 캘린더) |
| 📅 이번 주 일정 | 월~일 한눈에 (구글 캘린더) |
| 📚 오늘 시간표 | 요일별 과목 |
| 🎒 오늘 준비물 | 요일별 준비물. 누르면 챙긴 표시 |
| ⏳ D-Day | 소풍·방학까지 며칠 |
| 🌤️ 오늘 날씨 | 기온과 우산 안내 (Open-Meteo) |
| 💌 엄마 한마디 | 아이에게 남기는 메모 |
| 📞 비상 연락처 | 눌러서 바로 연락. 페이스타임·전화·문자 중 선택 |
| 💧 물 마시기 | 하루 몇 컵 마셨는지 |

아이패드처럼 통화 기능이 없는 기기에서는 **페이스타임 오디오**가 가장 확실합니다.
카카오톡은 앱을 열 수만 있고 상대를 지정할 수 없습니다.

시간이 정해진 할 일에는 타이머가 붙습니다. 시작을 누르면 큰 화면으로 카운트다운이 돌고, 끝나면 알람이 울립니다.

## 구글 캘린더 연결

이 저장소는 공개라서 접속 주소와 암호를 넣어두지 않았습니다. 기기마다 한 번씩 설정해 주세요.

1. `google-calendar-relay.gs` 를 script.google.com 새 프로젝트에 붙여넣기
2. 맨 위 `SECRET` 을 원하는 암호로 변경
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
4. 나온 주소를 앱의 ⚙️ → 구글 캘린더 연결에 입력

캘린더 이름은 `우리딸일정` 과 `하교시간` 을 씁니다. 일정 제목 앞에 `2:00 피아노` 처럼 시각을 적으면 그대로 읽어냅니다.

## 저장

기록은 브라우저 안(localStorage)에 기기별로 저장됩니다. 기기 간 공유는 아직 안 됩니다.
